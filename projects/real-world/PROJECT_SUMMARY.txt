Port: N/A (Command-line)

Components:
  ✓ 11 Java classes
  ✓ Picocli CLI framework
  ✓ Models: Dependency, Project, LockFile, DependencyGraph
  ✓ Parsers: PomParser (XML), JsonManifestParser
  ✓ Repository: MavenRepository (simulated .m2)
  ✓ Resolver: DependencyResolver with conflict resolution
  ✓ Graph: GraphVisualizer, LockFileGenerator
  ✓ Example files: sample-pom.xml, sample-manifest.json

Features:
  • Parse POM.xml and JSON manifests
  • Dependency resolution algorithm
  • Transitive dependency handling
  • Version conflict resolution
  • Lock file generation (JSON)
  • Dependency graph visualization (PNG)
  • Text-based dependency tree
  • Maven-compatible repository structure
  • Multiple CLI commands

Commands:
  • install <manifest>    - Install dependencies
  • tree <manifest>       - Show dependency tree
  • graph <manifest>      - Generate visual graph
  • lock <manifest>       - Create lock file
  • info <manifest>       - Show project info

Build: mvn clean package
Run: java -jar target/package-manager-1.0.0-jar-with-dependencies.jar
